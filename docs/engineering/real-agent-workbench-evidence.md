# 真实 Agent 工作台接入

日期：2026-08-28。范围：已确认的阶段 3 自然语言只读链路。不是生产部署，也不包括业务写入、跨站 SSO、应用生成发布。

## 实现

- 旧手工编号查询入口已替换为自然语言问题、当前任务、回答、实际工具记录和个人查询历史。页面不内置答案；刷新重新读取平台持久任务，切换企业清除旧数据。
- DS Agent Task 使用原生 DocType 持久化；服务器决定用户、企业及成员绑定版本，request_id 防止重复创建。普通成员不能用通用 REST 绕过任务 API 查看他人记录。
- 专用 worker 只负责领取任务；任务 capability 随机生成，只存哈希，限定任务与 180 秒有效期，完成或过期失效。业务 Runtime 不持有平台 worker API 密钥、业务 Site 密钥或开通密码。
- 每次任务使用独立 Docker 容器。只读文件系统、移除 capabilities、禁止提权、进程数上限、单并发、384 MiB / 0.1 CPU。只挂载 SDK 依赖、本项目运行代码与当前任务凭据，不挂载项目 `.env`、其他任务或 Docker socket。
- 主机协调进程从明确指定的 provider 文件读取三个配置键，不执行 Shell 内容，不扫描其他项目。SDK 子进程环境清理后启动；会话使用任务临时目录，结束清理。
- 使用固定 SDK/Runtime 0.1.1rc1；Linux 依赖由项目 requirements.lock 的版本与哈希安装。仅三个 MCP 工具：获准字段、获准记录、获准名称搜索；无 Shell、任意 HTTP、数据库或写工具。
- 工具事件由平台真实 ERP 调用保存，不能由模型提交伪造的执行记录。成功至少需要一次真实工具读取与完成的模型回答。错误、超时、撤权明确失败，不自动重跑任务。

## 权限与历史语义

工具每次重新检查平台成员、绑定版本及业务 Site 当前权限；读取进行期间成员变更会阻止结果返回。成员或企业绑定版本变化后旧任务不可访问，列表只显示当前绑定的任务。

历史是当时获准读取的快照：仅在业务 Site 调整角色、没有修改平台绑定时，不会追溯删除已保存历史。这不等于角色撤销会同步撤销所有历史数据；生产保留策略尚需单独处理。运行时共享验证网络也不是完整的生产网络隔离验证。

## 验证层次

整套 Python 回归已独立运行：72 passed，118.80 秒；前端 35 passed，4.46 秒。随后“任务级拒绝不停止 worker”修复完成，独立复跑任务 API、运行器及真实容器集成：21 passed，75.62 秒。明确 403/417 仅终结当前任务；500 或网络结果不明不覆盖、不重跑。

- 前端行为测试：自然语言提交、刷新恢复、企业切换、迟到结果隔离、权限拒绝清缓存、历史交错加载、手动恢复和 CSRF。
- 真实 Frappe / ERP 测试：任务幂等、跨用户和跨企业拒绝、专用 worker、并发领取、短期 capability、过期持久化、读取期间数据库事务撤销。
- 真实 Docker / SDK / MCP / ERP 测试：仅模型替换为同一隔离容器内的 loopback SSE 测试服务；验证真实模型请求只有三个工具，工具实际返回 ERP 物料，结果与事件保存到平台。
- 最初测试容器无法连接本机 loopback 模型服务（TRANSPORT，主机未收到模型请求）；改用同容器 loopback 测试服务，未修改正式 worker 路径，也没有切到宿主机业务 Runtime。
- 自动化任务在测试后按本次创建 ID 精确清理，不把替身回答留在用户查询历史。
- 真实页面已验证企业选择、自然语言输入及未启用服务时的 HTTP 503 错误展示；没有任务生成或替代答案。当时常驻付费 worker 未启动，测试心跳已清理；授权后的验证见下节。
- 官方模型验收在用户明确授权后执行，见下节；与上述替身测试分别记录。

## 授权后真实模型与页面验收

2026-08-28 用户明确“授权启用”：允许本项目最多三次真实验收任务，并启用后续用户主动发起的付费查询。实际完成两次任务，未使用第三次额度；一个任务可能包含多轮模型请求，不代表仅两次 HTTP 请求。未测量账单金额。

使用项目显式 `.env` 配置、DeepSeek 官方 API、`deepseek-v4-flash` 和固定 SDK/Runtime；未读取其他项目凭证。真实页面由已登录普通成员选择企业并提交问题，真实隔离容器执行工具并保存结果。

| --- | --- | --- |

两条验收记录保留在各自企业的个人查询历史中；本次没有创建、修改业务单据。上述空搜索仅证明当前用户在甲企业的该查询没有可见匹配，不扩大为所有权限下绝对不存在。

付费 worker 已作为本机独立进程启动并核实存活，等待用户查询；任务容器结束后清理。未安装开机自启，电脑或进程停止后需要重新启动。首次启动误用了虚拟环境解释器符号链接的解析目标，在加载依赖时退出，尚未请求模型；改用虚拟环境解释器原路径后成功。

当前提供真实模型与真实 ERP 读取链路，但业务数据仍为隔离站点合成数据，不代表接入了用户生产企业，也不是公网部署或生产验收。

## 本地启动

已存在的平台和业务站点基础上：

```sh
sh infra/prepare_agent_runtime.sh
.venv/bin/python infra/setup_agent_worker.py
.venv/bin/python -m dsherp.agent_worker --profile .runtime/agent-worker.json --provider-env .env
```

`setup_agent_worker.py` 仅首次执行，已有账户拒绝替换凭证。启动前必须确认费用授权和 provider 配置。协调进程退出后服务不再接单；挂起任务到期明确失败。业务入口为 `http://platform.localhost:18083/app/dsherp-home`。

常驻验证容器调整为 3712 MiB / 1.9 CPU，为唯一按需 Agent 容器预留额度；合计不超过原授权 4096 MiB / 2 CPU。未修改其他服务或上游核心，未拉取新镜像。
